PHỞ ĐẠI CHIẾN V7 — CẬP NHẬT TRỌN BỘ, KHÔNG CHÉP CODE
====================================================
1. GIẢI NÉN file ZIP; mở thư mục PHO_DAI_CHIEN_V7_TRON_BO.
2. Vào GitHub kho trantienbg2004-rgb/pho-dai-chien.
3. Xóa các tệp cũ (cả những file HTML sai vị trí và file cũ trong public).
   ĐỪNG xóa cả kho GitHub và ĐỪNG xóa dịch vụ Render.
4. Tại THƯ MỤC GỐC GitHub, bấm Add file > Upload files.
5. Từ thư mục V7 vừa giải nén, Ctrl+A chọn TẤT CẢ NỘI DUNG BÊN TRONG,
   kéo thả vào GitHub (gồm server.js, game-engine.js, game-data.js,
   package.json, README.md, HUONG_DAN_CAP_NHAT.txt, thư mục public và tests).
6. XEM LẠI: trong public phải có admin.html, index.html, theme.css, shared.js.
   Ngoài thư mục public KHÔNG có file admin.html hoặc index.html.
7. Commit changes, đợi Render hiện Live. Nếu cần: Manual Deploy > Deploy latest commit.
8. MỞ https://pho-dai-chien.onrender.com/health
   PHẢI CÓ "version":"7.0.0". Nếu chưa thì Render chưa chạy bản mới.
9. Tạo PHÒNG MỚI ở /admin; gửi link /play cho sinh viên.
10. Chơi thử 1 vòng: chốt sớm; chơi vòng khác để tự hết giờ.

BẢN V7: Admin 2 cột trên PC, người chơi tốt trên điện thoại;
4 vòng 8 bài toán, 72 biến cố; chốt sớm và tự chốt ở máy chủ;
công bố rõ quyết định -> biến cố -> tác động -> lợi nhuận -> bài học.
